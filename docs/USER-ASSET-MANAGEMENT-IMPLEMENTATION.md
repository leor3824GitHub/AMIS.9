### 1. MyAssets Page (`apps/blazor/client/Pages/User/MyAssets.razor.cs`)

#### Implemented Features:
- **Load User Assets**: Fetches physical assets from backend API
- **View Asset Details**: Opens dialog with asset information

- **Return Assets**: Returns assets to inventory with condition notes

#### API Endpoints Used:
- `SearchPhysicalAssetsEndpointAsync()` - Query physical assets in custody

## Technical Notes

### API Client Structure
The API client is auto-generated from OpenAPI/Swagger specification:
- Location: `apps/blazor/infrastructure/Api/ApiClient.cs` (27,182 lines)
- Generated by: NSwag/NJsonSchema
- All DTO classes are partial classes with JSON serialization attributes

### Response Types
All API responses use specific DTO classes without generic wrappers:
- `PhysicalAssetResponsePagedList` - Contains `Items` property (not `Data`)
- `IssuanceResponsePagedList` - Contains `Items` property (not `Data`)
- `CreateIssuanceResponse` - Contains `Id` property (no `Success` flag)
- `ReturnPhysicalAssetResponse` - Contains `AssetId` property (no `Success` flag)
- `AcceptIssuanceResponse` - Contains `IssuanceId` property (no `Success` flag)
- `RejectIssuanceResponse` - Contains `IssuanceId` property (no `Success` flag)

### Request Types
Command structures discovered during implementation:
- `SearchPhysicalAssetsCommand` - PageNumber, PageSize
- `SearchIssuancesCommand` - PageNumber, PageSize
- `CreateIssuanceCommand` - EmployeeId, IssuanceDate, TotalAmount
- `ReturnPhysicalAssetCommand` - Id, Condition, Reason, AcceptedBy, QuantityReturned
- `AcceptRequest` - SignedByEmployeeId (NOT Remarks)
- `RejectRequest` - RejectionReason (NOT Remarks)

### IssuanceResponse Structure
Important: `IssuanceResponse` does NOT have a `Status` property. Instead:
- `IsClosed` (bool) - Indicates if the issuance is closed/completed
- Filter pending issuances using: `Where(i => i.IsClosed == false)`

## Error Handling
All methods implement comprehensive error handling:
```csharp
try
{
    // API call
    var response = await ApiClient.SomeEndpointAsync(...);
    if (response?.Id != null)
    {
        Snackbar?.Add("Success message", Severity.Success);
        // Reload data
        await LoadData();
    }
}
catch (ApiException apiEx)
{
    Snackbar?.Add($"API Error: {apiEx.Message}", Severity.Error);
}
catch (Exception ex)
{
    Snackbar?.Add($"Error: {ex.Message}", Severity.Error);
}
```
